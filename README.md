# STAT 184 - Homework 4.3

## Project Overview

This repository contains my Homework 4.3 assignment for STAT 184 at Penn State. The assignment was about using R and Quarto to create a report with data, graphs, tables, and written explanations.

## Data Sources

For this assignment, I used the diamonds dataset from the ggplot2 package in R. The dataset includes information about diamonds, such as their price, size, and clarity.

I used this data to compare diamond widths between different clarity groups.

## Project Plan

My plan was to complete the analysis in RStudio, create the graphs and tables, and render the final report as a PDF.

I also planned to upload my files to GitHub, create a development branch, use issues to track my work, and merge my changes into the main branch.

More information about my plan is in PLAN.md.

## Repository Files

- **README.md** - Explains what the project is about.
- **PLAN.md** - Explains my plan for the assignment and GitHub repository.
- **HW43.qmd** - Contains the R code and written explanations.
- **HW43.pdf** - The final PDF report from Homework 4.3.

To run the report, download the files from this repository and open the QMD file in RStudio. Make sure the required R packages are installed, then render the QMD to PDF.
