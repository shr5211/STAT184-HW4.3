# STAT 184 - Homework 4.3 Project Plan

## Part 1: Homework 4.3 Plan

### Goals

My goal for Homework 4.3 was to create a report using R and Quarto. The report needed to include data analysis, graphs, tables, and written explanations. I also wanted to make sure the report was organized and easy to understand.

### Needs

To complete this assignment, I needed:
  
  - R and RStudio
- Quarto
- The tidyverse package
- The diamonds dataset
- A QMD file to write my report
- A PDF version of my completed report

### Steps

1. Create a QMD file in RStudio.
2. Load the required packages and data.
3. Clean and organize the data.
4. Use R to analyze the data and create graphs.
5. Create a table showing summary statistics.
6. Add written explanations about the results.
7. Render the QMD file into a PDF.
8. Check the PDF for errors and make any needed changes.
9. Submit the completed report.

## Part 2: GitHub Repository Plan

### Goals

My goal was to create a public GitHub repository for Homework 4.3. I wanted to organize my files and use GitHub to track the changes I made. I also wanted to learn how to use branches, issues, commits, and pull requests.

### Needs

To complete this part of the assignment, I needed:
  
  - A GitHub account
- GitHub Desktop
- My completed QMD and PDF files
- A README.md file
- A PLAN.md file
- A main branch and a development branch
- At least two GitHub issues

### Steps

1. Create a public GitHub repository for Homework 4.3.
2. Clone the repository using GitHub Desktop.
3. Create a development branch from the main branch.
4. Create two GitHub issues to track my work.
5. Add my QMD and PDF files to the development branch.
6. Complete the README with information about my project.
7. Create a project plan explaining my goals and steps.
8. Make commits with clear messages explaining my changes.
9. Push my changes to GitHub.
10. Create a pull request to merge the development branch into main.
11. Merge the pull request and close the completed issues.
12. Check that all files are on the main branch.

## Maintaining the Repository

If I need to make changes in the future, I will use the development branch to update my files. I will make commits to keep track of what I changed and use GitHub issues to organize any new tasks.

I will also update my README and project plan when needed. After checking my changes, I will use pull requests to merge them into the main branch.

## Final Goal

By the end of the assignment, my repository should contain my completed QMD and PDF files, a README, and a project plan. It should also show that I used branches, commits, issues, and pull requests correctly.
